海外社媒 / 社区运营方向的个人简历单页网站。

## 预览

本地直接用浏览器打开 `index.html` 即可预览。

在线地址（GitHub Pages）：`https://<你的GitHub用户名>.github.io/<仓库名>/`

## 技术

- 纯 HTML + CSS 单文件，无构建依赖
- 响应式布局，适配手机端
- 内容结构：个人摘要 / 工作经历（时间轴）/ 核心能力 / 作品与账号 / 教育背景

## 更新内容

编辑 `index.html` 后提交推送即可自动更新线上页面：

```bash
git add index.html
git commit -m "update: 简历内容更新"
git push
```
